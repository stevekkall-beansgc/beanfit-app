# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/stevekkall-beansgc/beanfit-app/security/advisories/new). Do not disclose details in a public issue, discussion, or pull request.

Please include the impact, reproduction steps, and affected version or commit when known. Redact credentials, cookies, pairing codes, device tokens, and personal data from the report.

## Scope

This policy covers the beanfit-app Cloudflare Worker and D1-backed application, including authentication, sessions, CSRF, pairing approval, device credentials, server-rendered HTML, access control, and submitted device profiles or recommendations. It does not cover the separate beanfit CLI, Google, GitHub, Cloudflare, or other third-party services; report vulnerabilities in those services to their respective maintainers.
